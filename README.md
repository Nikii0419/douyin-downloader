# 抖音视频解析下载网页（iPhone Safari 适配）

## 部署方式
1. 将整个文件夹上传到一个新的 GitHub 仓库。
2. 登录 Vercel，选择 **Add New → Project**，导入该仓库。
3. Framework Preset 选择 **Other**，直接 Deploy。
4. 部署完成后，用 iPhone Safari 打开 Vercel 提供的网址。
5. Safari 分享按钮 → **添加到主屏幕**，即可像网页 App 一样使用。

无需配置环境变量。

## 使用
抖音 App → 分享 → 复制链接 → Safari 打开网站 → 粘贴 → 解析 → 下载。
iPhone 通常会将下载文件保存到「文件」App。要保存到照片，打开下载文件后点分享 →「存储视频」。

## 重要说明
- 解析逻辑使用抖音公开网页详情接口。抖音可能调整接口、风控或限制部分作品，因此不能保证所有链接永久可用。
- 当前版本主要支持公开视频分享链接；私密、已删除、仅好友可见、直播、图集等内容可能无法解析。
- 视频 CDN 域名有可能变化；若出现“视频源暂时无法访问”，需要更新 api/download.js 的允许域名。
- 请仅下载自己拥有或已获授权的内容，并遵守抖音平台规则和当地法律。
- 这是自托管项目。部署者需自行承担服务器、带宽及合规责任。
